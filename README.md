# UI/UX Development - ITI Study Material

## 1. Description

Notes and lab exercises collected during ITI's UI/UX development track, organized by topic. It is a study archive, not a runnable application.

## 2. Technologies and Versions

Topics covered by the folders: HTML5, CSS3, responsive design, JavaScript (client-side, advanced, ES6), jQuery, Node.js, MongoDB, Nuxt, TypeScript, PWA, networking, security, source control, plus freelance, communication and Gen AI topics. No single toolchain or versions apply.

## 3. Requirements and Dependencies

- A browser and a text editor to read and run the examples
- Individual exercises may need Node.js (for the Node/Mongo/Nuxt topics)

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/UI-UX-development-ITI.git
cd UI-UX-development-ITI
```

Open the folder for the topic you want and follow the files inside it.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- One folder per topic (`Html 5/`, `CSS 3/`, `responsive/`, `client-side/`, `advanced javascript/`, `ecma 6/`, `Jquery/`, `node js/`, `node/`, `mongo/`, `nuxt/`, `typescript/`, `Pwa/`, `Network/`, `Seciurty/`, `source control/`, `freelance/`, `communication/`, `Gen AI/`).
- Each folder contains the exercises and notes for that topic.
